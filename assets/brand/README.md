# moxxy brand

## The mark

Two rounded squares, one rotated 45 degrees, woven through each other with a
true over/under at all eight crossings.

It reads as a **harness**: two straps bound into one structure that holds
something in place. That is what moxxy is around a model. It also reads as a
closed **loop** (the agentic loop) built from **swappable parts** (every block
in the framework), and the interlace only works because both strands give way
to each other in turn.

The weave is not decoration. The four `moxxy-weave` mask circles put the ink
strand back on top at four alternating crossings; without them the two squares
are merely stacked, and the mark loses its depth.

## Palette

| Token | Hex | Use |
|---|---|---|
| Ink | `#0B0D12` | Primary strand, wordmark, dark backgrounds |
| Signal | `#FF4A1E` | Second strand, accents, focus states |
| Paper | `#FFFFFF` | Ink's inverse on dark |
| Ink Lift | `#2A3247` | Gradient top stop (mark, icon background) |
| Signal Lift | `#FF8A3D` | Gradient top stop (mark) |

Signal is deliberately warm. Developer AI tooling is saturated with blue and
violet, and orange holds contrast on both a white page and a dark terminal.

## Files

| File | Use |
|---|---|
| `moxxy-mark.svg` | The mark. Default everywhere. |
| `moxxy-mark-gradient.svg` | Expressive version for hero art and large web use. Not for UI chrome or print. |
| `moxxy-wordmark.svg` | Type only. The two x's carry the same weave as the mark. |
| `moxxy-lockup.svg` | Mark plus wordmark, horizontal. The default logo. |
| `moxxy-lockup-stacked.svg` | Vertical lockup for square slots and hero blocks. |
| `moxxy-icon.svg` | App icon: rounded, own background. Desktop (`apps/desktop/public/logo.png`), PWA, favicon at 64px and up. |
| `moxxy-icon-square.svg` | App icon for iOS and Expo: full bleed, square, **no alpha channel**. iOS masks the corners itself and rejects an icon that carries alpha, and `apps/mobile/test/iosPlist.test.ts` enforces it by reading the IHDR colour type. |
| `moxxy-og.html` | Social card source, rendered to `png/moxxy-og.png` at 1200x630. |
| `moxxy-mark-mono.svg` | One colour, for print, embroidery, stamps, and the macOS menu bar. `png/moxxy-mark-mono-22.png` and `-44` ship as `apps/desktop/public/trayTemplate.png` + `trayTemplate@2x.png`, which AppKit tints for the light and dark bar. |
| `moxxy-mark-signal.svg` | One colour in Signal. Holds contrast on both a white and a dark ground, so surfaces that ship a single raster for both themes use it (`apps/mobile/assets/moxxy-mark.png`). |
| `alternates/` | The other seven directions, still on the table. |
| `png/` | Rasterised exports, transparent (RGBA), regenerated by `build.sh`. |

Every source has a `-dark` (ink swapped for paper) generated alongside it.

**The one-colour mark is a different drawing, not a recolour.** In two colours
the interlace is carried by the colour change at each crossing. Flatten that to
one ink and the mark collapses into a solid eight-pointed silhouette, so
`moxxy-mark-mono.svg` breaks each strand where the other passes over it instead.
It is a source file in its own right; only `-mono-white` is derived from it.

The wordmark is drawn as geometric paths, not set in a typeface, so it needs no
font to be embedded and no licence to be tracked.

## Animation

The mark is symmetric under a quarter turn, so **rotating it 0 to 90 degrees is
a whole loop**: the animation lands back on itself with no seam, and the weave
survives because the mask that lifts the ink strand at four crossings turns with
the strands. Rotate the mark as one piece. Counter-rotating the two squares
against each other changes the angle between them, moves the crossings, and
slides the mask off the strands it is supposed to lift.

Loading states use this: `.moxxy-avatar-loader` in `apps/desktop/src/styles.css`,
the pre-React splash in `apps/desktop/index.html`, and `MoxxyMarkSpinner` in
`apps/mobile`. All three run the same quarter turn over 3.4s, linear, and stop
under `prefers-reduced-motion`.

## Rules

- **Clear space**: one stroke width of the mark (22 units at a 256 viewBox, so
  8.6% of the mark's height) on every side. Nothing enters it.
- **Minimum size**: mark 20px, horizontal lockup 120px wide, stacked lockup
  90px wide. Below 20px use `moxxy-icon.svg`, whose background carries the
  shape when the interlace stops resolving.
- **Do not** recolour a single strand, close the weave gaps, add a stroke or
  shadow, place the flat mark on a busy photo (use the icon), or rebuild the
  wordmark in a system font.

## Rebuilding

```sh
./assets/brand/build.sh          # colour variants + PNG exports
CHROME=/path/to/chrome ./assets/brand/build.sh
```

Edit only the four sources (`moxxy-mark`, `moxxy-wordmark`, `moxxy-lockup`,
`moxxy-lockup-stacked`) plus `moxxy-mark-gradient` and `moxxy-icon`. Everything
else in this folder is generated, so hand edits to a `-dark`, `-mono` or `png/`
file are overwritten on the next build.
