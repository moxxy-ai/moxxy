Typing a slash in the composer opens a menu of modes, skills, workflows and actions, in the main window and in the Mini Chat, so an automation can be run straight from the chat; `/plan <prompt>` and `/goal <objective>` typed in full work too. The Mini Chat header gets a voice conversation button. The mode and auto-approve notes above the field are a dot and a line of text instead of a capsule. The terminal opens with the Moxxy mark and no longer cuts off its last row.
