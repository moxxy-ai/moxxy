Agent connections close four gaps found in the final check. A one-off request (a summary, a skill draft, memory, the research plan) gives the agent its instructions as instructions, no longer as words the person said. An agent the person comes back to hears the turns another connection ran meanwhile (`AgentStepRequest.missedTurns`, `renderMissedTurns` in `@moxxy/sdk`). A skill file saved while the conversation runs reaches the agent at its next turn. An MCP server set up both in Moxxy and in the agent reaches the agent once, through its own setup.
