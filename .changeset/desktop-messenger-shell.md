The desktop app now opens on the conversation. The icon rail on the left is gone. The sidebar is a list of your runs, grouped by workspace, and each run shows an avatar, when it was last active and its latest message. Extensions, Settings, Collaborate, Automations, Apps, Channels, Mobile and Voice have moved into one menu at the bottom of the sidebar, and into the command palette, which now opens with ⌘K / Ctrl+K from any screen. Nothing was removed. The header above a run is lower and quieter: search, focus mode and rename sit behind one button, and the run's state appears only when it needs you.
