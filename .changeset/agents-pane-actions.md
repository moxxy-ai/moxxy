The Agents pane says more and does more with what the agent runs in the background. The Agents tab counts what runs now in the chat. Each work has a menu (⋯ or a right click) with Stop while it runs and Copy command, the command the agent ran (Copy name when the chat does not hold the call that started it). "Whole project" lists what runs now in every chat of the project, with the chat's name, and stops it there.
