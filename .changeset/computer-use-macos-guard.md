Computer Use (macOS helper): the user stays in charge. Pressing Escape stops Computer Use like the Stop button, without taking Escape away from the user's apps. Pause holds the next action and fades the agent cursor; after Resume the action is not replayed and the model looks at the app again first. Real mouse input waits for a moment in which the user is not using the mouse or keyboard, and is refused if they keep going, so the agent never fights the user's hand.
