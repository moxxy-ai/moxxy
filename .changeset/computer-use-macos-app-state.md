Computer Use (macOS helper): list installed and running apps and resolve app names to bundle identifiers (by identifier, display name or bundle path), reporting ambiguous and unknown names. Reading an app's state launches it in the background when needed and returns its focused window as indexed accessibility elements: layout-only containers are flattened, element indices stay the same for as long as the element exists, and password fields are marked secure without their value ever being read. The state also carries a JPEG of just that window within the vision image budget, with every element's frame in the image's pixels; when there is no image, the reason is given.
