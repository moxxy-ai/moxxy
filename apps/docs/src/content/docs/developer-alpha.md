title: Developer alpha
description: Supported paths, experimental areas, and how to give useful feedback.
---

The developer alpha tests whether a developer can install moxxy, connect one
model account, complete useful work in a project, understand approvals, and
resume the run without learning the runtime architecture.

## Supported path

- Node.js 20.10 or newer on macOS and Linux;
- Anthropic and OpenAI API keys;
- ChatGPT OAuth and an existing Claude Code subscription session;
- local read, edit, command, and search tools;
- approvals, persisted runs, and default local memory;
- extensions after the first successful run.

## Experimental

Channels, background services, collaboration, automations, voice, mobile,
agent-authored apps, third-party runtime blocks, and governed fleet operations
are experimental. They live behind advanced CLI commands or the desktop's
**More** menu.

Governed workstation profiles are a design-partner preview, not a claim of a
fleet control plane, compliance certification, or production SLA.

## Give feedback

Report reproducible bugs in
[GitHub Issues](https://github.com/moxxy-ai/moxxy/issues). Use
[GitHub Discussions](https://github.com/moxxy-ai/moxxy/discussions) for product
feedback.

Include your OS, architecture, Node version, install method, selected model
connection, time to first useful result, first attempted task, unclear words or
approvals, and whether resume worked. Never include secrets.
